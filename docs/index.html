Know how long every paper is.

Page Count adds a #Pages column to your Zotero item list. It reads the page range, the page field, or the PDF itself.

Three places to find the count.

01

Page range

A pages value such as 12–19 counts as 8 pages. Lists such as 12, 14–16 work too.

02

Page field

If there is no range, the plugin uses the numPages field.

03

The PDF

Otherwise it uses the page count Zotero stores for the item's oldest PDF.

Install in a minute.

  1. Download page-count.xpi from the latest release.
  2. In Zotero, open Tools → Plugins.
  3. Click the gear icon, choose Install Plugin From File…, and select the file.
  4. Right-click the column header of your item list and choose #Pages.
